# Dzakwan Bahar Prahara — Technology & Program Portfolio

A responsive, single-page scrolling portfolio designed to position Dzakwan for a broader range of roles:
- Program Officer / Program Support
- IT Support / Technical Support
- Operations / Project Support
- Web / Digital / Technology roles

## Main features
- Sticky responsive navbar
- Full-scroll landing page
- Experience timeline / card layout
- Dedicated Projects showcase with editable placeholders
- Activities section + dedicated Activities page
- Skills grouped for technical + program/operations work
- Education & certifications section
- Contact section
- Export to PDF via browser Print / Save as PDF
- CSS print layout for a cleaner A4-oriented output

## Project placeholders
Each project card can be changed directly in `index.html`:
- Replace `PROJECT IMAGE` placeholder with an `<img>`
- Change project title, year, description
- Edit technology tags
- Update Live Demo / Repository / Case Study URLs

## Run locally
Open `index.html` directly or use VS Code Live Server.
